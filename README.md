# Luma Kids — стартовый сайт-каталог

Готовый адаптивный статический сайт для Luma Kids: детская одежда собственного производства, акцент на оптовых заявках и запросах розничных покупателей.

## Состав
- `index.html` — главная страница, каталог, производство, оптовая форма, контакты.
- `styles.css` — адаптивный дизайн и анимации.
- `app.js` — RU/UZ-переключатель, фильтры, поиск, карточки товара, модальное окно и подготовка заявки.
- `vercel.json` — простая конфигурация для статического размещения.
- `assets/` — папка для реальных фото и логотипа (пока пустая).

## Запуск локально
Самый простой способ — открыть `index.html` в браузере. Для более корректной проверки запусти Live Server в VS Code.

## Размещение на Vercel
1. Распакуй ZIP.
2. Загрузи папку в новый GitHub-репозиторий.
3. В Vercel нажми Add New → Project и импортируй репозиторий.
4. Для статического сайта оставь Framework Preset = Other, Build Command пустым, Output Directory `.`.
5. После публикации проверь RU/UZ, фильтры и форму на телефоне.

## ВАЖНО ПЕРЕД ПУБЛИКАЦИЕЙ
1. **Карточки и цены:** две первые позиции взяты из доступного текста текущего сайта (`Пижама Sweet Dreams`, `Спортивный костюм Lavanda`). Их цены и размерные ряды — только предварительные сведения, обязательно подтвердить у владельца. Остальные позиции — демонстрационные карточки, заменить реальными товарами или удалить.
2. **Фотографии:** внешние фотографии с Unsplash используются только как временные изображения-концепты, не как подтверждённые фотографии Luma Kids. Заменить фотографиями производства и реальных изделий.
3. **Контакты:** Telegram `@lumakids_uz` и Instagram `@lumak1d` перенесены из текущей версии сайта; подтвердить, что это официальные аккаунты. Телефон и email не придуманы и не добавлены.
4. **Форма:** сейчас она подготавливает текст заявки и даёт скопировать его. Она **не отправляет** заявку владельцу и не хранит персональные данные. Чтобы включить отправку, нужно подключить проверенный endpoint, Telegram-бота/серверную функцию или CRM. Секретные токены нельзя помещать в публичный `app.js`.
5. **Производительность:** цифра выпуска 500–600 изделий в день не указана как публичный факт в новой версии, пока владелец не подтвердит актуальность.
6. **Возраст:** ассортимент на текущем сайте содержит и товары для младенцев, тогда как описание цеха указывает примерно 2–12 лет. Проверь фактическую возрастную линейку и оставь только актуальные модели.

## Редактирование каталога
Массив `products` находится в начале `app.js`. Для каждой модели укажи:
- `name.ru` и `name.uz`
- `category`: `sets`, `tops` или `sleep`
- `image`: URL или путь к локальному изображению
- `sizes`, `price`, `tag`, `desc`

Для локального фото положи файл в `assets/`, например `assets/tracksuit-lavanda.jpg`, и укажи `image: "assets/tracksuit-lavanda.jpg"`.

## Технические особенности
- Без сборщика и npm-зависимостей.
- Адаптивный мобильный интерфейс.
- Поддержка `prefers-reduced-motion`.
- Каталог фильтруется и ищется на клиенте.
- Форма проверяет обязательные поля и готовит текст заявки; отправка не имитируется.
